# Studio Schoon

Schoonmaak-app voor een studio zonder vaatwasser, met inductieplaat, douchegordijn en de wc in de badkamer.

- **Start**: wat je vandaag moet doen, en per klus een knop om te beginnen
- **Stap voor stap**: één stap tegelijk, met het juiste product en de juiste doek, een timer voor inwerktijd, en automatisch afvinken
- **Lijsten**: dagelijks, wekelijks, maandelijks en per seizoen; ze beginnen vanzelf opnieuw
- **Kast**: je eigen producten met dosering, voorraad en boodschappenlijst
- **Zoeken**: problemen zoals kalk, schimmel of een aangebrande pan

Open `index.html` in je browser. Voortgang wordt alleen in die browser bewaard.
